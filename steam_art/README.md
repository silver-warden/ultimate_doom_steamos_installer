# steam_art/

Steam grid artwork for the DoomRunner non-Steam shortcut. **Not original
work and not covered by the repository's GPL-3.0** — collected from
community Steam Deck art packs (decky css loader downloads), of DOOM-fandom
origin: the icon is a remixed classic-DOOM player sprite and the hero art
imitates DOOM Eternal key art, so id Software's rights ride on them
regardless of how they were made. Provenance and terms otherwise unknown.

They are bundled purely as optional eye-candy; delete or replace them with
your own `<appid>_hero.png` / `<appid>.png` / ... files at any time — the
installer skips missing art gracefully.
